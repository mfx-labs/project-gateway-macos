# Project Gateway for macOS v0.2.0

## Highlights

- New one-time `pgw tunnel` setup for the macOS tunnel workflow.
- New normal-use `pgw up` command (foreground).
- `pgw help` command surface.
- Canonical `pgw project add / list / remove` commands.
- User-first README and onboarding workflow.

## Correctness

- **WP7-ERR-1 (`distinguish git config read failures from drift`):** an
  unreadable `.git/config` is now represented as a configuration-read failure
  and fails closed under the existing unsupported-state behavior, instead of
  being misreported as `.git/config content changed`.

## Security

- `tunnel-client` pinned to v0.0.10.
- Official release origin pinned.
- Architecture-specific SHA-256 verification before installation.
- Runtime API Key persisted in the macOS Keychain.
- Literal secret not stored in the repository, tunnel profile, or logs.
- Foreground-only operation.
- No LaunchAgent / autostart installed by this workflow.
- Production trust-path and test-seam corrections completed.

## Documentation

- README rewritten as a user-first onboarding guide (Quick Start → install →
  tunnel setup → project registration → daily use → troubleshooting).
